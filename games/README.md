# Game workspaces

Create one with `npm run new:game -- my-game`, then `npm install` and `npm run format` from the root. Complete DESIGN.md before choosing the engine or building gameplay. See the root README for the development and publication workflow.

Each game owns its code, runtime assets, game.json, README.md, DESIGN.md, and ASSETS.md. A draft is compiled in CI but excluded from deployment. First game: [Apex Coast](apex-coast/README.md), a mobile-first 3D driving alpha using Three.js and cannon-es.
